Repository adalah sebuah tempat penyimpanan terpusat yang digunakan untuk mengelola seluruh file dalam suatu proyek pengembangan perangkat lunak (software development). Repository dapat berisi source code, dokumentasi, konfigurasi, serta berbagai file pendukung yang dibutuhkan dalam proses pengembangan aplikasi.

Dalam bidang teknologi informasi, repository umumnya digunakan bersama Git untuk melakukan version control, yaitu sistem yang memungkinkan developer melacak perubahan kode, mengelola versi proyek, serta berkolaborasi dengan developer lain secara lebih terstruktur.
# LAPORAN DAY 1 PROYEK WORKSHOP

## 1. Rangkuman Materi yang Disampaikan Selama Workshop

Pada Day 1 Proyek Workshop, materi yang dipelajari berfokus pada pengenalan repository serta penggunaan Git dan GitHub dalam proses pengembangan perangkat lunak (*software development*).

Repository merupakan tempat penyimpanan dan pengelolaan file proyek yang dapat berisi source code, dokumentasi, konfigurasi, serta file pendukung lainnya. Repository membantu developer mengorganisasi proyek agar lebih terstruktur dan mudah dikelola.

Selain itu, dipelajari juga Git sebagai sistem *version control* yang berfungsi untuk mencatat setiap perubahan pada kode program. Sementara itu, GitHub merupakan platform berbasis web yang digunakan untuk menyimpan repository secara online, membagikan proyek, serta memfasilitasi kolaborasi antar-developer.

Melalui materi tersebut, peserta memperoleh pemahaman dasar mengenai bagaimana sebuah proyek teknologi dikembangkan, dikelola, dan didokumentasikan menggunakan tools yang umum digunakan dalam industri teknologi.

## 2. Poin-Poin Penting atau Pengetahuan Baru yang Dipelajari

Beberapa pengetahuan baru yang diperoleh selama workshop antara lain:

1. Memahami konsep repository sebagai tempat penyimpanan dan pengelolaan file proyek.
2. Mengetahui fungsi Git dalam mencatat dan mengelola perubahan kode program.
3. Memahami penggunaan GitHub sebagai platform penyimpanan repository secara online.
4. Mengetahui perbedaan antara local repository dan remote repository.
5. Memahami pentingnya version control dalam menjaga riwayat perubahan proyek.
6. Mengetahui bahwa Git dan GitHub dapat membantu proses kolaborasi dalam pengembangan perangkat lunak.
7. Memahami pentingnya dokumentasi proyek agar kode program lebih mudah dipahami dan dikembangkan oleh orang lain.

## 3. Pendapat Pribadi tentang Day 1 Proyek Workshop

Menurut saya, Day 1 Proyek Workshop merupakan pengalaman yang bermanfaat karena memberikan pemahaman dasar mengenai tools dan teknologi yang digunakan dalam proses pengembangan perangkat lunak. Materi yang disampaikan juga menambah wawasan saya mengenai pentingnya pengelolaan proyek secara terstruktur, khususnya melalui penggunaan Git dan GitHub.

Hal yang paling menarik bagi saya adalah memahami bagaimana repository dapat membantu developer dalam mengelola kode program, melacak perubahan, serta bekerja sama dalam sebuah tim. Namun, melalui workshop ini, saya mulai memahami hubungan antara Git, GitHub, dan repository dalam sebuah alur kerja pengembangan perangkat lunak.

Saya berharap materi yang telah dipelajari pada hari pertama dapat menjadi dasar untuk memahami dan mengembangkan proyek pada tahap selanjutnya. Saya juga menyadari bahwa mempelajari teknologi tidak cukup hanya dengan memahami teori, tetapi perlu diimbangi dengan praktik secara langsung agar pengetahuan yang diperoleh dapat diterapkan dengan baik.
